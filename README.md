# 🤖 ผู้ช่วยอ่านข้อความ LINE เฉพาะกลุ่มงาน & สรุปรายงานรายสัปดาห์ (Weekly Report)

ระบบบอทสำหรับติดตามงานในกลุ่ม LINE Official Account (`TanaBot`) คัดกรองเฉพาะกลุ่มงาน บันทึกข้อความลงฐานข้อมูล และจัดทำรายงานสรุปประจำสัปดาห์ด้วย AI (Google Gemini)

---

## 🌟 ฟังก์ชันหลัก
1. **คัดกรองเฉพาะกลุ่มงาน**: บันทึกเฉพาะข้อความจากกลุ่มที่ลงทะเบียนไว้ ไม่ยุ่งกับกลุ่มอื่น
2. **กรอง Noise อัตโนมัติ**: ละเว้นข้อความสั้นหรือคำทักทายทั่วไป เช่น "555", "ok", "สวัสดี"
3. **จัดทำรายงานสรุปประจำสัปดาห์**:
   - 🎯 งานที่สำเร็จแล้ว (Completed)
   - 🔄 งานที่กำลังดำเนินอยู่ (In Progress)
   - ⚠️ ปัญหา / อุปสรรค (Issues & Blockers)
   - 📌 ข้อตกลงและ Action items สัปดาห์ถัดไป
4. **ส่งอัตโนมัติ**: ตั้งเวลาส่งเข้ากลุ่มทุกวันศุกร์ เวลา 17:00 น.
5. **สั่งสรุปได้ทันที (On-Demand)**: สมาชิกในกลุ่มสามารถพิมพ์ `#สรุปงาน` เพื่อดูรายงานทันทีได้ตลอดเวลา

---

## 💬 คำสั่งสำหรับใช้งานในกลุ่ม LINE
- `#สรุปงาน` หรือ `#สรุปสัปดาห์นี้` : สั่งให้ AI จัดทำและส่งรายงานสรุปทันที
- `#สถานะ` : ตรวจสอบจำนวนข้อความที่บันทึกสะสมในรอบ 7 วัน
- `#ลงทะเบียน` : เปิดโหมดบันทึกข้อมูลสำหรับกลุ่มนี้
- `#ช่วยเหลือ` : ดูรายการคำสั่งทั้งหมด
